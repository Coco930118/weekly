## 試験中（実測が出たら判定する）

判定に使うのは `reference/weekly_metrics.json` の実測だけ。**中止と拡大はCocoの判断。** 判定した週は、結果と用量の変更を作業報告に書く。

### X診断のウィット一滴（週2〜3本）

- 比較の目安は、その週のX診断7本の中央値

### Threads診断のウィット一滴（週2〜3本）
- 8/25週の2本（8/27・8/30）で試験中
- 判定は**コメント表示**で見る（ウィット行がコメント側にあるため）
- 継続＝ウィット適用回のコメント表示の平均が非適用回の8割以上／8割未満＝翌週1本に減らして再試験／**2週連続で8割未満なら中止をCocoに提案**
- コメント到達率が2週連続で3割未満なら、本文への移動をCocoに提案（最後の手段）

### 逆説の言い切り型（拡散帯・週1〜2本）
- 初回＝2026-08-25週 th_21「大切にされたい／大切にしたい」
- **2週続けて拡散帯の中央値を下回ったら中止。上位に入ったら配分に正式昇格**し、型配分の目安（実験10・場面4・問い3）を実測で組み替える

### Threads拡散帯の「前へ進む力」3点（9/8週の作成時に試験投入・2026-08-26 Coco承認）
背景：8/25週のThreadsが「後ろ向きのつぶやき」に見えた（Coco指摘）。実データで数えたところ、ルール違反はゼロで**用量の偏り**だった——「昔」開き5本（うち2本が19:00枠の外）、ぼかし締め9本（43%）、伝聞三連鎖（8/25〜26のth_01・02・04）。一方、**初速4本の実測では「んだよね」締めが1位・2位**で、語尾は原因ではなかった。残った仮説が下記①。

- [ ] **① 冒頭2行に、体が動く絵を1つ入れる**（最有力）
  実測の根拠：th_02（64）＝立つ・行く・飲んで戻るの3動作／th_04（57）＝夕飯を先に決めた／th_01（26）＝「聞くのをやめた」＝行動の不在。伝聞・実験構造・語尾まで同型で、差は冒頭だけだった
- [ ] **② 伝聞マーカーを散らす**（「〜人がいる」「〜って」「〜みたい」）。1本2回まで・**同日および3本連続で並べない**。
  理由：語り手ルール（現在進行の恋愛の試行錯誤はわたし目線で書かない）を守ると実験が全部相談者に振られ、「わたしはこうしてる」の現在形が実験を一度も担わない週になる。ルールは崩さず、配置で散らす
- [ ] **③ 「昔は／昔のわたし」開きは19:00「昔と今」枠のみ**（8/25週は07:00・10:00に2本漏れた）
- **判定**：8/25週（ぼかし・伝聞多め）と9/1週（言い切り12本・「昔」開き2本）が自然なA/Bになっている。**両週の実測が揃った時点で拡散帯の中央値を比較**し、①②③の本採用・用量をCocoに提案する。8/25週の中身は途中で直さない（比較が壊れるため）
- **やらないと決めたこと**：拡散帯の命令形解禁／CTAでの「変われる」約束／権威の前出し。力強さは**わたしの決断の描写**だけで出す（読者への号令は入れない）
