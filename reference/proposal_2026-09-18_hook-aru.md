## 2. なぜ要るか——いまのルール2には「どっちを選ぶか」が書いていない

ルール2は型を5つ並べています（①逆説 ②不都合な事実 ③対比 ④意外な結論 ⑤実話・会話）。
**並んでいるだけで、選ぶ基準がありません。** 基準がないと、いちばん作りやすい①逆説に倒れます。

**実測（2026-09-18・9/22週35本・目視）**：佇まい枠2本を除いた33本のうち、**13本が「うまい」側**でした。

| 外れ方 | 本数 | 実物 |
|---|---|---|
| **人物のラベリング**（性格の話にする） | 1 | x_04「感情的だと言われたく**ない人ほど**、感情がないわけじゃない。」 |
| **因果の断定**（AするとBになる、と言い切る） | 3 | x_08「褒め言葉としても読める指摘は、**いちばん届かない**まま流れる。」／th_05／th_07 |
| **読者側で翻訳が要る**（書き手の語で書く） | 3 | x_01（人格／動作）／x_13（**独立**）／th_03（**気づく力**） |
| **定義の言い換え**（〜は〜とは違う） | 2 | th_08「動けない日は、失敗**ではなく**動かないと決めた日」／th_14 |
| **箴言・一般論**（どこかで聞いた形） | 3 | th_10「やめるほうが、始めるより勇気が要る。」／th_11／th_17 |
| **条件＋処方**（観察になっていない） | 1 | th_04 |

**13本／33本＝約4割。** しかもこれは**機械チェックを全部通ったあと**の数字です（要修正0件の状態で13本）。

**すでに直した2本が、差を示しています**（2026-09-18 Coco判定）。

|---|---|---|

## 3. 条文案（このまま `rules/posts.md` に貼れる形）

置き場所は**ルール2の「型を5つに散らす」の表のすぐ下、Cocoの見本9本の前**。

```markdown
##### 「うまい」より「ある」を採る（2026-09-18 Coco決定・恒久ルール／**全35本**）

**逆説を作りにいかない。現場にある矛盾を見つける。** 結果として逆説になるのはいい。
ひねって作ると、SNS用に整えた跡が残る。

**判定は一つ。読んで「うまいことを言った感」が先に立ったら、現場の観察に取り直す。**

| | うまい（取り直す） | ある（採る） |
|---|---|---|
| 恋愛 | 断れない人ほど、自分が何を好きなのか分からなくなる。 | 相手の予定を先に聞くと、自分の予定はいつも後になる。 |
| 組織 | きれいに整えて任されるほど、動けなかった理由は自分に戻る。 | 範囲まで決めて任せたのに、手が止まったままの人がいる。 |

- **「うまい」に倒れる形は5つ**——①**人物のラベリング**（「〜人ほど」で性格の話にする）②**因果の断定**（AするとBになる、と言い切る）③**読者側で翻訳が要る語**（書き手の語で書く）④**定義の言い換え**（「〜は〜とは違う」）⑤**箴言**（どこかで聞いた形）
- **「ある」の作り方は一つ**——**その回の素材の中で、実際に起きていることを、性格を言わずに書く。** 起きた行動・現場のズレ・言われた言葉だけを置く
- **①逆説は消えない。** 消すのは**逆説を目的にすること**。見つけたズレが結果として逆説になるのはよい
- **上の「探すのは『AとBのズレ』」と同じことを、判定できる形にしたもの。** あちらは「ズレを冒頭に置く」までで、**ズレを"作る"のと"見つける"のを分けていなかった**
```

## 4. 機械か、生成か（`CLAUDE.md`「禁止ルールは、足す前に決める」を通した結果）

| 手順 | 判定 |
|---|---|
| ① 機械で検出できるか | **できない。** 「うまいことを言った感」は固定の語句ではない。「〜人ほど」を機械で禁じると、Cocoの見本「**部下を助けるほど**、判断力を奪うことがある。」まで落ちる |
| ② 生成ルールに翻訳できるか | **できる。** 「ひねるな」ではなく「**素材の中で実際に起きていることを、性格を言わずに書く**」。上の条文案はこの形だけを置いている |
| ③ どちらも無理なら足さない | 該当しない |

**②で通ったので、足してよい形です。** 「やめろ」の形（比喩ゼロがそうだった）では守られません。
