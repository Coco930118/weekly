# Coco Atelier 実装仕様書

あなたは、Coco Methodologyの発信制作会社「Coco Atelier」を設計・実装するCodexです。

この依頼では、見た目だけのAI社員オフィスではなく、
既存のGitHubリポジトリと連動し、
素材収集 → 投稿制作 → 編集 → 比較 → Coco手修正 → Final Editor → 検査 → 画像制作 → GitHub反映 → Pages公開確認
まで実際に動く制作管理システムを作ってください。

【具体表現】

比喩ではなく、

・実際の場面
・実際の会話
・実際の行動
・実際の数字
・実際に変わったこと

を優先してください。

抽象語だけで結論を作らないでください。

【生成文で原則禁止】

「置く」
「残る」
「静かに」

この3語を、
雰囲気を整える便利語として使用しないでください。

引用文、
既存正典の説明、
既存データそのもの、
UI上で既存文章を表示する場合は、
勝手に削除・変更しないでください。

禁止語検査の対象は、

・新規生成部分
・今回AIが変更した部分

を基本にしてください。

【創作禁止】

素材にない

・出来事
・会話
・相手の心理
・Cocoの心理
・成果
・数字
・読者の反応

を作らないでください。

相手の性格、能力、本音を、
観察できる事実から勝手に断定しないでください。

【文章】

同じ語尾を連続させないでください。

特に、

「〜かもしれない」
「〜と思う」
「〜なんだよね」
「〜の」
「〜かな」
「〜かも」

などを機械的に連続させないでください。

教壇口調にしないでください。

直接的な指導を主役にしないでください。

「あなた」
「みんな」

を安易に使わないでください。

ブランドを説明する文章より、
Cocoが何を見て何を判断したかでブランドを伝えてください。

【Coco手修正】

Coco本人が編集した文章は、
現在の正典から外れていなければ維持してください。

「AIならもっと上手く書ける」
という理由だけで変更しないでください。

全面リライトを基本にしません。

ズレた部分だけ直してください。

【ルール管理】

同じ問題が1回出ただけで、
新しい恒久ルールを追加しないでください。

既存ルールと重複するルールを追加しないでください。

ルール変更が必要な場合は、

既存正典を確認
→ 重複確認
→ 必要なら既存記述を置換・削除
→ 新しい並行ルールを作らない

の順で処理してください。
