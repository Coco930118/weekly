## 診断 共通ルール（X診断・Threads診断 共通・毎回必ず適用）

対象：X診断・Threads診断のすべての回。生成／グローアップ時に、各回のフックと選択肢に必ずこの2ルールを適用する（既存ルールに上乗せ・衝突時は本ルールを優先）。

### ルール1：冒頭フックの「その瞬間」法（爆発力を上げる）
設問（「あなたに一番近いのはどれ？」等）の前に、感情を刺激する“その瞬間”を再現する一文を必ず先頭に置く。読者を説明でなく「場面」に放り込んでから設問へ渡す。
- 型：「〈相手の一言 or 突きつけられた状況〉」と〈言われた／なった〉瞬間、あなたはどう〈返す／動く〉？
- 一般論・説明（「〜な人へ」「〜についての診断です」）で始めない
- 読者が実際に食らう“セリフ・場面”を先頭に置き、痛点をその場で再生させる
- 強い一文 → 設問 → 選択肢の順。強い一文は投稿フレーム（フック＋設問＋CTAのコピー単位）の先頭に入れる
- 例：「『あなたの経験は、うちの業界では通用しない』と言われた瞬間、あなたはどう返す？」
- NG例：「あなたはどのタイプ？」「〜に関する診断です」（弱い・説明的）

### ルール2：選択肢のバランス＆導線設計（答えの位置を毎回変える）
- 【最重要・答えを固定しない】どれが“効く／理想”の選択肢かは、回ごとに変える。毎回同じ位置（例：いつもC・いつもD）を正解にしない
- 【正解を1つに絞らない回も混ぜる】全部に一理ある／状況次第で答えが変わる回もあってよい。診断の面白さは「わたしはこれだ」という発見であって、“正解当て”ではない
- 全選択肢を誠実に肯定で拾う。「受け入れ・引く・無言・無視」に見える選択肢も、消極でなく“別の強さ”として描く（逃げに見せない）
- 重心（理想）を置く回でも“これが正解”と言い切らず、読者が自然にそこへ向かう温度で。ただし理想の位置（A/B/C/D）は毎回動かす
- 【回またぎのバランス】週7本／複数回で、理想の位置を散らす：連続で同じ位置が正解にならないようにする

### ルール3：締めCTAは「答えがコメントにある」と名指しする（2026-08-23 Coco決定・恒久ルール／**Threads診断のみ**）
**適用範囲＝Threads診断（2026-08-24 Coco決定で限定）。X診断は新形式の固定CTA「いちばん近いの、一文字だけコメントで教えて。」を使うため、本ルールの対象外**（X診断のコメント到達率は134%で、答えを見に行く行動が既に起きているため名指しが不要。詳細は本ファイルの「X診断の新形式」）。

実測（8/18週Threads診断）：本文43表示に対しコメント8表示＝**到達率18%、6日中3日はゼロ**。同週のXはnote添付コメントが本体の7〜9割読まれており、正反対。北極星「感情はある。依存はしない。」も会員導線もコメント側にあるため、**コメントが読まれない診断は、エンゲージメントにも収益導線にも接続しない**。
- 締めCTAは「A〜D、コメントへ」だけで終えない。**その回の答えがコメントにあることを、中身を名指しして添える**（一行・20〜35字目安）
- 型：「A〜D、いちばん近いのをコメントへ。〈その回の答えの名指し〉は、コメントに〈書いた／置いた／まとめた〉。」
- **名指しは中身まで**（「解説はコメントへ」のような一般語で終えない）。ただし答えそのものは書かず、飢餓感を残す
- **表現は毎回変える**（既視感ゼロチェック③と併走。7本で同じ言い回しを並べない）
- X診断の実測は揃った（到達率134%＝問題なし）。X診断は2026-08-24からの新形式に移行したため、本ルールはThreads診断専用として運用する

### 自己評価チェック（各回・全ルール）
- [ ] 設問の前に、感情を刺激する“その瞬間”の一文が先頭にあるか（説明始まりでないか）
- [ ] その一文がフレーム（コピー単位）の先頭に入っているか
- [ ] 全選択肢を肯定で拾い、消極的に見える選択肢を“別の強さ”として描けているか
- [ ] 今回の“理想／効く選択肢”の位置が前回までと変わっているか／正解を1つに絞らない回も混ざっているか
- [ ] 重心を置く回でも、“正解”と言い切らず自然な導線になっているか
- [ ] 締めCTAが、その回の答えがコメントにあることを中身まで名指ししているか／7本で言い回しが重複していないか

### 文体（診断・2026-08-25 Coco承認／shindanから移設）
- **本文に「あなた」「みんな」を使わない。**（設問の主語は置かない）
- **声はドメイン別に固定し、混ぜない。** 温度＝組織と仕事は**冷徹な軍師**の声、距離＝恋愛と関係は**慈愛に満ちた哲学者**の声。
※一人称「わたし」・「んです」禁止・語尾は ね／よ／だ は `CLAUDE.md`「文体」が正典。ここでは重複させない。

## Threads診断 返信欄の構成（2026-08-24 Coco決定・恒久ルール／新形式）

**8/25週の確定稿をもって、Threads診断の返信欄（reply_1）はこの形に固定する。** 旧形式（`──────────────` の区切り線で A〜D を1ブロックずつ長文解説する形）は廃止。長い解説はコメントを開いた読者を最後まで運べていなかったため、4行に圧縮して読み切れる長さにする。

### reply_1 の並び（この順で固定）
1. **フックの一文を再掲**（本文＝frameと同じ書き出し。開いた読者が場面に戻れるようにする）
2. **受け口＋正体の言語化**（1段落。受け口の言い回しは7本すべて変える）
3. **4行の箇条書き**：`・〈選択肢の要約〉 ── 〈一行解説〉` を4本。選択肢A〜Dと同じ順で並べ、**全部を肯定で拾う**。A〜Dの記号は書かず、選択肢の要約で示す
4. **まとめ段落**（1〜2文。その回の核心を言い切る）
5. **素材の一行**（割り当てエピソードの**実際の言葉**。創作ゼロ。`episodes_soshiki.json` の原文表現に寄せる）
6. **北極星**「感情はある。依存はしない。」
7. **ウィット一滴**（週2〜3本のみ・下記⑤のルール）
8. **診断リンク**：`▼ 8問 / 約1分` ＋ URL（`https://shindan-flax.vercel.app/kankei/MM-DD`）。旧「▼ 8問 / 約1分で、いまどこに立っているか」は廃止（2026-08-25・8/25週から適用済み。直前の橋渡しの一行が約束を担うため、すぐ下で旧文の約束を繰り返すと橋渡しが無効になる。X診断の短縮形と同じ実測判断）

### 本文（frame）に「持ち帰れる一行」を置く（2026-08-24 Coco決定・恒久ルール）
実測：8/18週のコメント到達率は18%（本文43→コメント8・6日中3日ゼロ）。**答えが読者の8割に届いていない**ため、1通目だけで1つ持ち帰れる形にする。
- **位置**：選択肢の下・締めCTAの上に一行（`takeaway_line` フィールドにも保持する）
- **中身**：その日のコメントの結論の圧縮。**新規の創作はしない**
- **コメント側と同じ文にしない**（本文＝言い切り／コメント＝理由、で角度を変える）。同一文だと、開いた読者が「さっき読んだ」に当たり、最後まで読む理由が消える。締めCTAで「答えはコメントにある」と名指ししている以上、ここが同じでは導線が壊れる

### 橋渡しの一行は固定要素（2026-08-24 Coco決定・恒久ルール）
診断リンクの直前に置く一行。**7本すべて同一文で固定する。**
> さっきの4択が1問目。残り7問で出るのは、その場面ではなく、いつもの癖のほう。

- **役割**：①1問目がすでに埋まっていると伝える（ゼロからの開始ではなく続き）②約束を「その場面」から「いつもの癖」に差し替える——**2つの独立した仕掛けを1文で担っている**
- **グローアップ時に7本バラバラに書き換えない。** 既視感ゼロチェック③の対象外として扱う（北極星と同じ固定要素）。変えるときは週単位で7本まとめて変える
- **理由**：(1) 内容ではなく導線の説明なので、毎回変えると読者に読み解く手間が増える (2) 定型だからこそ「この診断はいつもこれ」の認知が育つ (3) **文言を崩すと、2つの仕掛けのどちらが効いたか実測で分離できなくなる**
- **実装との整合**：進捗は 1/8 から始まり、埋まらない（コメントのURLは全員共通1本のため、読者の選択をサイトは知り得ない）。この一行は「4択＝1問目」と言っているだけで答えが埋まるとは言っていないので、嘘にならない。着地側は1問目にだけ「投稿で見た、あの問い。」を出して約束を果たす

### 引き算の一行を優先する（2026-08-24 Coco決定・恒久ルール）
「持ち帰れる一行」は、可能なかぎり**「やめていいこと」の形**にする。足し算（〜しよう）より引き算（〜をやめていい／〜は守れない／〜は成立しない）を優先する。
- **根拠は原理01**（相手や環境を変えない。自分の側で今日決められることだけを渡す）。相手を変えるのは足し算、自分がやめるのは引き算で、**引き算のほうが原理と一致する**
- **実測の裏づけ**：歴代最高3,299は「自分から連絡するのをやめてみた」＝引き算の実験。引き算は①今日できる（即効性）②やめた結果は来た／来なかったのどちらも情報になる（結果両方提示と噛み合う）③一回ごとに完結して次の場面でも使える（会員価値と噛み合う）
- **ただし切りっぱなしにしない**：引き算は行動としては簡単でも、**実行時の心理的な負荷が高い**（連絡しない数時間がいちばんしんどい）。やめた後に空く時間をどう過ごすかまでを、処方の射程に入れる（35投稿ルール3①「切ったあとに必ず代わりにこれをやるを置く」の診断版）
- 適用範囲：Threads診断の持ち帰れる一行。35投稿・noteへの展開は実測を見てからCocoに提案する

### 本文（frame）の並び（2026-08-24 Coco決定）
その瞬間フック → 設問 → 選択肢A〜D → **持ち帰れる一行** → 締めCTA。リンクは置かない。

### 本文（frame）にリンクを入れない（実測由来）
8/18週の実測で、**本文にURLを置いた日はリーチが約8分の1（60→7.2）に落ちた**。リンクは**コメント末尾の1本だけ**にする。

### 会員導線は返信欄に置かない
**診断リンクの先にメンバーシップURLがあるため**（2026-08-23 Coco確認）、reply_1 に会員導線の一文は入れない。収益導線は診断ページ側で受ける。旧ルール「返信欄の締めをメンバーシップへの飢餓感にする」は、この新形式では診断リンクが代替する。

### 素材の一行の扱い（比喩ゼロとの関係）
素材の一行はエピソード在庫の言葉を引くが、**比喩ゼロ・言い切りルール（下記④）は素材の一行にも適用する**。原文に比喩がある場合は、意味を変えずに素直な言葉へ言い直す（例：E321「土台のほうが相手の側にあった」→「いつの間にか誰かに支配されていた」＝同エピソードの別の原文表現に寄せる）。素材の言葉を守ることと比喩ゼロは両立させる。

### X診断の返信欄はコメント②を削除する（A4・shindanから移設・2026-08-25 Coco承認）

### ①焦点の一貫性チェック
- 4択が全て同じ軸（「あなたならどう行動するか」）に揃っているか。他人への感想・評価など異なる軸の選択肢が紛れていないか
- フレーム（フック）の主語・前提と、選択肢の主語・前提が一致しているか（フックで語られていない要素が選択肢に急に出てこないか）
- ターゲット層（板挟みの中間管理職・想いが届かない経営者）が読み終えた後、頭の中が「そういうことだったのか」と整理される着地になっているか

### ②舐められず好かれるチェック
- 正解として提示する選択肢が、「舐められない（芯がある・迎合しない）」と「好かれる（角が立たない・攻撃的でない）」を両方満たしているか
- comment_1でその選択肢が「最も機能する型だ」等の言い切りで、明確に一つだけ選ばれていることが読み取れるか
- 誤答の選択肢が、なぜ機能しないかを感情的な批判ではなく構造的な理由で説明できているか

### ③既視感ゼロチェック（2026-08-19 Coco決定・恒久ルール）
35投稿の既視感ゼロルール（ルール1）をX診断7本にも適用する。
- **同じ週のX診断7本全体で**、似た表現・似たメッセージ・似た構文を使わない。フック・選択肢・comment_1の締め・comment_2の内省の問いを横断して見る
- 「〜と〜は別のことだ」「〜と〜は違う」などの構文、同テーマのキーワードを週内で重複させない
- 前週のX診断7本とも突き合わせ、週またぎで同じ表現・同じ締め方に寄せない

### ④比喩ゼロ・言い切りチェック（2026-08-19 Coco決定・恒久ルール）
- **X診断では比喩を使わない**。核心は、そのままの言葉で言い切る
- 言いたいことを別の絵に置き換えない。実際に起きる出来事・行動の言葉で書く（フック・選択肢・comment_1・comment_2すべてが対象）
- 分かりにくい箇所を直すときも、意味を変えずに、同じことを素直な言葉で言い直す（意味ごと差し替えない）

### ⑤設問の型チェック（2026-08-23 Coco承認・恒久ルール／実測由来）
**診断の生命線は「コメント到達率」（コメント表示÷本文表示）。** 解説・「明日の一手」・会員導線はすべてコメント側にあるため、答えを見に行かせられなければ診断は成立しない。2026-08-18週の実測で、**到達率を決めているのは設問の型**だと分かった（本文表示は曜日ではなく配信からの経過日数でほぼ決まるが、到達率は比なので経過日数の影響を受けない）。

| 設問の型 | 例 | 実測到達率 |
|---------|-----|-----------|
| **見立て型** | 「何を疑う？」「どう見る？」 | **170% / 166%** |
| **順番型** | 「何を先に置く？」「どこから話す？」 | 144% |
| **自己分類型** | 「一番近いのはどれ？」「一番気にするのは？」 | 114% |
| **行動型（素）** | 「どう動く？」「どうする？」 | 96% / 96% |

- 理由：「どう動くか」は自分の行動だから読者はすでに答えを持っていて、選んで終わる。**「何を疑うか・どう見るか」は自分の見立てが正しいか分からないから、答え合わせにコメントを開く**
- **設問は見立て型・順番型を基本にする。素の行動型（どう動く／どうする）は週2本まで**。自己分類型は中間なので配分の調整に使う
- 選択肢の軸と設問の軸は必ず一致させる（①焦点の一貫性チェックと併走）。行動の選択肢に見立ての設問を被せない
- この配分は `reference/weekly_metrics.json` の実測でのみ上書きしてよい

### 実測の取り方（診断共通・2026-08-23 Coco決定）
- 診断の数字は**必ず2値**で受け取る：**本文（設問＝frame）の表示回数／コメント（答え＝X診断はcomment_1・comment_2、Threads診断はreply_1）の表示回数**
- あわせて**「いつ時点の数字か」を記録する**。本文表示は配信からの経過日数にほぼ比例するため、経過日数が揃っていない日同士を強弱で比べない（2026-08-18週で「週後半に逓減」と読み違える事故が実際に起きた）
- **形式変更の判定はコメント到達率で行う**（ウィット一滴試験も同じ。ウィット行はコメント側にあるため）

## X診断の新形式（2026-08-24 Coco決定・恒久ルール／#078〜適用）

**根拠は実測**：2026-08-18週のX診断はコメント到達率134%（本文211／コメント283・日別96〜170%）。同週のThreads診断18%と正反対で、X診断は「設問を読んで終わり」にならず、答えを見に行く行動が確実に起きている。**2通に分けると2通目まで読まれる保証がないため、答えを1通にまとめて確実に届ける。**

### 構成
| 要素 | 中身 |
|------|------|
| **本文（frame）** | その瞬間フック → 「四つとも、間違いではない。」→ A〜Dの選択肢 → 固定CTA → `#温度の4択 NNN` |
| **固定CTA** | **「いちばん近いの、一文字だけコメントで教えて。」**（旧「いくつ当てはまった？」を置き換え） |
| **コメント（comment・1通のみ）** | もやもやの正体 → A〜Dの解説（見るのは一点／明日の一手）→ 締めの一段 → 3点まとめ → 結び → ［該当回のみ］佇まいの一行 → **接続の一行** → 「▼ 8問 / 約1分」→ 診断URL |
| **診断URL** | `https://shindan-flax.vercel.app/soshiki/MM-DD`（日付ごとに1ページ）。**コメントの最終行** |

### 廃止したもの（旧#077までとの違い）
- **comment_1 / comment_2 の2通構成 → comment 1通に統合**
- **バックカタログ行「これまでの診断：〜」を置かない**（蓄積感の提示は診断サイト側が担う）。ただし `shindan_series.json` の `technique_log` の更新は継続する（通し番号と過去テーマの台帳）
- **メンバーシップCTA・定番プロミスをコメントに置かない**。**会員導線は診断サイトの結果ページ側にある**（2026-08-24 Coco確認）。収益モデルとの整合はサイト側で取れているため、コメントに戻さない
- **内省の問いを最終行に置く旧ルールは終了**（最終行は診断URL）
- **診断共通ルール3（締めCTAで答えの在り処を名指し）はX診断に適用しない**。Threads診断専用ルールとして運用する

### 接続の一行（2026-08-24 Coco決定・恒久ルール／診断アクセス0の対策）
コメント末尾の診断URLの直前に、**投稿とは違う約束**を一行置く。

> **「さっきの4択が1問目。残り7問で出るのは、その場面ではなく、いつもの判断のほう。」**

- **背景**：全6週で診断アクセスが0だった。原因は投稿と診断が**同じ約束（いまどこに立っているか）を繰り返していた**こと。投稿を読んだ時点で用が済んでいるので、診断に行く理由がなかった
- **仕掛けは2つ**：①「1問目はもう埋まっている」＝着手コストを下げる ②**場面 → 癖**へ約束を変える＝投稿にない価値を作る
- **原則**：投稿＝その場面の答え／診断＝**繰り返している判断の癖**。ここを同じ約束にしない
- **この一行は固定要素。グローアップで7本バラバラに書き換えない**（既視感ゼロチェックの対象外）。変えるときは週単位で7本まとめて変える——1本ずつ崩すと、「進捗の付与」と「約束の差し替え」のどちらが効いたのか実測から分離できなくなる
- **「▼ 8問 / 約1分」は「残り7問」にしない**。診断の進捗は1/8から始まり、事前に埋めることは構造上できない（コメントのURLは全員共通1本のため、読者がどれを選んだかサイト側が知り得ない）。「4択が1問目」は4択＝1問目と言っているだけで、答えが埋まるとは言っていないので整合している
- 旧「いま、どこに立っているか。8問 / 約1分で出る。」は廃止

### 禁止語の回避（2026-08-25 Coco承認・恒久ルール／**9/1週から適用**）
「渡す」「渡し」「仕組み」は、**読者に出る新規の文（frame・comment）では言い換えで回避する**。
- **対象外**：在庫エピソードの原文・型のタイトル（E377「材料を渡して、決定を返す」等）・正典の定義文。素材の言葉をそのまま使う箇所は原表記のまま
- 言い換えると設問の焦点が崩れる場合は、変更せずCocoに二択で確認
- **遡及しないのは8/25週まで**（当初は9/8週開始と決めたが、2026-08-25 Cocoの指示で9/1週に前倒し。9/1週は適用済み）
- **機械チェックは適用週を区別しない。** 8/25週（#078〜084）で禁止語が5件出るのは正常＝対象外の週なので直さない。9/1週で1件残る「材料を渡して、決定を返す」はE377の型タイトルで、上の対象外に当たる

### 280字上限に注意（最重要・新CTAで超えやすくなった）
新CTAは44字、旧「いくつ当てはまった？」は20字で**+24字**。フックと選択肢が長い回は280を超える。**280を超えるとタイムラインで折り畳まれ、設問と締めCTAが初見で見えなくなり、診断そのものが成立しない。**
- **生成・グローアップのたびに全7本の frame を計測する**（全角2・半角1・改行1／`#温度の4択 NNN` を含めた全体）
- 超えた回は**フックを引き算して収める**（足して整えない）。選択肢とCTAは削らない
